# Separado do requirements.txt de proposito: no Windows o PyPI so tem o codigo
# fonte do llama-cpp-python, e o pip tenta COMPILAR o llama.cpp (exige Visual
# Studio Build Tools com C++ e CMake). O run_local.bat instala o
# requirements.txt a cada execucao — com a lib la, quem so usa o Gemini teria a
# subida da API quebrada por um compilador que nao precisa.
#
# O indice abaixo tem wheels pre-compiladas para CPU, que evitam a compilacao
# quando existe wheel para a sua versao do Python. Para GPU NVIDIA, troque
# "cpu" por "cu121"/"cu124" conforme o CUDA instalado.
